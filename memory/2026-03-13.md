## 🐛 修复：Astro Content Schema 错误

**问题：** 博客构建失败，多个新闻联播文章 frontmatter 不符合 schema

**错误信息：**
```
[InvalidContentEntryDataError] blog → cctv-news-2026-03-08 data does not match collection schema.
  category: Invalid enum value. Expected '航海' | '国际时政' | '生活思考', received '时政'

[InvalidContentEntryDataError] blog → cctv-news-2026-03-07 data does not match collection schema.
  description: Required
  category: Invalid enum value. Expected '航海' | '国际时政' | '生活时政', received '时政'
```

**根本原因：**
- Astro schema 要求 category 必须是 `'航海' | '国际时政' | '生活思考'` 之一
- 旧文章使用了 `'时政'`（不在枚举中）
- 3 月 7 日文章使用了 `summary` 字段而非 `description`

**修复内容：**
1. ✅ `cctv-news-2026-03-07.md`: 
   - `summary` → `description`
   - `category: 时政` → `category: '国际时政'`
   - `tags: [新闻联播，CCTV，时政]` → `tags: ['新闻联播', 'CCTV', '时政']`
   - 删除 `draft: false`（不需要）

2. ✅ `cctv-news-2026-03-08.md`:
   - `category: 时政` → `category: '国际时政'`
   - tags 格式修正

3. ✅ `cctv-news-2026-03-09.md` 及以后：格式已正确
