## 📝 学到的东西

1. **WordPress REST API 很好用** - 可以程序化发布文章、上传图片
2. **图片迁移要同步进行** - 先下载图片上传到媒体库，再替换文章中的链接
3. **URL 编码问题** - 文件名需要正确处理 URL 编码和解码
4. **特色图片 vs 正文图片** - WordPress 中特色图片单独设置，正文图片在内容中
