# 2026-03-09 - 新闻自动发布流程修复

## 🔧 主要问题

**发现时间**：2026-03-09 心跳检查

**问题描述**：
- 新闻调度器 (`news-scheduler.js`) 每天北京时间 6:00 运行
- 但只生成 markdown 文件，**未自动发布到 WordPress**
- March 8 新闻文件已生成 (54KB)，但 WordPress 无新文章

**根本原因**：
1. `fetch-cctv-news.sh` 只生成 markdown 并提交到 Astro 博客 (已弃用)
2. `publish-daily-news.sh` 发布到 WordPress 但使用硬编码模板，不抓取真实新闻
3. 两个流程未串联

## ✅ 修复方案

**新建统一脚本**：`scripts/publish-cctv-wordpress.sh`
- 调用 `cctv-news-fetcher` 技能抓取真实新闻
- 解析 JSON 并生成 HTML 格式
- 通过 WordPress API 发布
- 同时保存 markdown 到本地存档

**更新调度器**：`news-scheduler.js`
- 从 `fetch-cctv-news.sh` 改为 `publish-cctv-wordpress.sh`
- 重启调度器进程 (新 PID: 1613)
