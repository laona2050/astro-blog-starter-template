# 📰 Tech News Digest

Daily tech news digest, auto-generated by [OpenClaw](https://openclaw.ai) agent.

## Structure

```
digests/
  YYYY/
    MM/
      tech-digest-YYYY-MM-DD.md
```

## Sources

- 🔵 RSS Feeds (AI labs, tech blogs, crypto news)
- 🐦 Twitter/X KOLs (AI researchers, tech executives)
- 🐙 GitHub Releases (major open-source projects)
- 🤖 Reddit (r/MachineLearning, r/LocalLLaMA, etc.)
- 🔍 Web Search (LLM, AI Agent, Frontier Tech)

## How to use

Each digest is a standalone Markdown file. You can:
- Read directly on GitHub
- Use any Markdown reader plugin to fetch by path pattern `digests/YYYY/MM/tech-digest-YYYY-MM-DD.md`
- Subscribe via RSS using GitHub's commit feed: `https://github.com/Ethanyoyo0917/tech-news-digest/commits/main.atom`
