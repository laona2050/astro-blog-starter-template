## ⚠️ 采购注意事项

### 1. 技术规格确认

- [ ] 额定功率 vs 峰值功率（确认持续输出能力）
- [ ] 电压等级（400V/800V/1000V+）
- [ ] 防护等级（IP68 必需）
- [ ] 海水防腐等级（C5-M 或更高）
- [ ] 工作温度范围（-20°C 至 +50°C）
- [ ] 最大转速和扭矩曲线

### 2. 配套系统

- [ ] 电机控制器（含再生制动）
- [ ] 电池系统（LFP 推荐）
- [ ] 充电系统（岸电 + 发电机）
- [ ] 控制系统（joystick/矢量推进）
- [ ] 监控软件（实时状态、故障诊断）

### 3. 安装要求

- [ ] 船体开孔尺寸和位置
- [ ] 结构加强要求
- [ ] 电气系统兼容性
- [ ] 冷却系统（海水直冷或热交换）
- [ ] 吊装和维护空间

### 4. 售后服务

- [ ] 保修期限（2-3 年标准）
- [ ] 备件供应周期
- [ ] 技术支持响应时间
- [ ] 培训服务（船员/技师）
- [ ] 全球服务网络覆盖
