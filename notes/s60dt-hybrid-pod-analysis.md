- 原版续航**远超**柴电混合（10,000 vs 3,500 海里）
- 原因：风筝帆系统 + 优化的船体设计 + 高效发动机

## 📊 详细续航计算（6-8 节经济航速）

### 功耗估算（60 尺双体，约 28 吨）

| 航速 | 推进功率 | 系统功耗 | 油耗 | 续航时间 | **续航里程** |
|------|----------|----------|------|----------|-------------|
| **6 节** | 60 kW | 75 kW | 19 L/h | 420 小时 | **~2,520 海里** |
| **7 节** | 90 kW | 110 kW | 28 L/h | 285 小时 | **~1,995 海里** |
| **8 节** | 130 kW | 155 kW | 39 L/h | 205 小时 | **~1,640 海里** |

**计算公式：**
```
柴油能量密度：10 kWh/L
发电机效率：85-90%
系统综合效率：80-85%
油耗 = 系统功耗 ÷ 10 ÷ 0.85 ≈ 功耗 × 0.118 L/kWh
续航时间 = 8000L ÷ 油耗
续航里程 = 续航时间 × 航速
```

## 🔧 电机冷却与噪音技术解答

### 问题：电机浸入海水中是否可以不用考虑发热和噪音？

#### 发热问题

**✅ 海水冷却优势：**

| 冷却方式 | 散热效率 | 复杂度 | 成本 |
|----------|----------|--------|------|
| 风冷 | 低 | 简单 | 低 |
| 淡水循环 + 热交换器 | 中 | 中等 | 中 |
| **海水直冷** | **高** | **简单** | **低** |

**海水冷却原理：**
```
电机定子 → 铝合金外壳 → 海水直接接触 → 高效散热
```

**优势：**
- 海水比热容大，散热效率是空气的 4 倍
- 无需额外冷却系统（泵、热交换器、管路）
- 电机可连续满负荷运行

**注意事项：**
| 风险 | 防护措施 |
|------|----------|
| 海水腐蚀 | 阳极保护、防腐涂层、316L 不锈钢 |
| 生物附着 | 防污漆、定期清理 |
| 密封失效 | 双重机械密封、油室监测 |
| 电化学腐蚀 | 绝缘设计、牺牲阳极 |

**结论：** ✅ 海水冷却**极大简化**发热管理，但需做好防腐和密封

---

#### 噪音问题

**✅ 水下电机噪音优势：**

| 噪音源 | 传统轴系 | 电动吊舱 | 降低 |
|--------|----------|----------|------|
| 发动机 | 75-85 dB | 65-70 dB（发电机舱） | -10-15 dB |
| 齿轮箱 | 65-75 dB | 无 | -100% |
| 轴系振动 | 60-70 dB | 无 | -100% |
| 螺旋桨空化 | 70-80 dB | 60-70 dB | -10 dB |
| **总体（舱内）** | **85-95 dB** | **65-75 dB** | **-20 dB** |

**为什么水下电机更安静：**

1. **无机械传动** - 电机直驱螺旋桨，无齿轮箱噪音
2. **水介质隔音** - 水是优良隔音介质，声音不易传入船体
3. **低转速高扭矩** - 电机可在低 RPM 输出最大扭矩，减少空化
4. **振动隔离** - 吊舱与船体柔性连接，振动不传递

**注意事项：**
| 噪音源 | 缓解方案 |
|--------|----------|
| 电机电磁噪音 | 优化绕组设计、PWM 频率 >20kHz |
| 螺旋桨空化 | 大直径低转速、优化桨叶设计 |
| 水流噪音 | 流线型吊舱外壳 |

**结论：** ✅ 水下电机**显著降低**噪音，舱内可降 20+ dB
