## 🚀 如何使用

### 方法 1：自然语言（推荐）

直接告诉助手您想做什么：

#### 发布文章
```
发布一篇新文章，标题是《我的航海日记》，内容是...
```

#### 上传图片
```
帮我上传这张图片到博客
```

#### 修改样式
```
把博客的 logo 改成圆形
```

### 方法 2：使用命令行工具

```bash
# 设置 Token
export GITHUB_TOKEN='ghp_xxxxxxxxxxxx'

# 发布文章
./blog-manager.sh post "文章标题" "文章描述" content.md

# 上传图片
./blog-manager.sh image ./photo.jpg

# 修复 MDX 语法
./blog-manager.sh fix src/content/blog/article.mdx

# 提交推送
./blog-manager.sh deploy "提交信息"
```

## 📋 技能特性

### ✨ 自动处理
- ✅ 创建 Markdown/MDX 文件
- ✅ 设置 frontmatter（标题、描述、日期）
- ✅ 检查并修复 MDX 语法错误
- ✅ Git 提交和推送
- ✅ 触发 Cloudflare 自动部署

### 🔧 自动修复
- `<` 符号后跟数字 → 改为"小于"
- HTML 注释 `<!-- -->` → JSX 注释 `{/* */}`
- 未闭合的标签
- 格式问题

### 📊 完整流程
```
用户提供内容 → 创建文件 → 语法检查 → 
自动修复 → Git 提交 → 推送 GitHub → 
Cloudflare 构建 → 2-5 分钟上线
```

## ⚠️ 重要提示

### Token 安全
- ⚠️ Token 相当于密码，请妥善保管
- ⚠️ 仅在当前会话使用
- ⚠️ 不要公开分享
- ✅ 建议设置 90 天过期时间

### 部署时间
- Cloudflare Pages 自动部署需要 **2-5 分钟**
- 刷新页面查看更新（Ctrl+F5 强制刷新）
- 可在 Cloudflare Dashboard 查看构建状态

### MDX 语法
- ❌ 避免 `<5` 这样的写法
- ✅ 改用"小于 5"
- ❌ 不要用 HTML 注释
- ✅ 使用 `{/* JSX 注释 */}`
