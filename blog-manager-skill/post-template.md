## 📝 写作提示

### 最佳实践
1. **标题清晰**：使用明确的章节标题
2. **段落简短**：每段 3-5 句为宜
3. **多用列表**：让内容更易读
4. **添加图片**：图文并茂更吸引人
5. **SEO 优化**：写好 description 和标题

### 避免的问题
- ❌ 不要在文章中使用 `<` 符号后跟数字（如 `<5`），改用"小于 5"
- ❌ 不要使用 HTML 注释 `<!-- -->`，如需注释用 `{/* */}`
- ❌ 避免过长的段落（超过 10 行）
- ❌ 不要忘记添加 description

### 推荐结构
1. 引人入胜的开头（引言）
2. 清晰的章节划分
3. 丰富的内容形式（文字、列表、表格、图片）
4. 有力的总结
5. 参考资料和标签
