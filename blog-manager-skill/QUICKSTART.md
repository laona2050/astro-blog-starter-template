## 🔑 首次配置

### 1. 获取 GitHub Token
1. 访问 https://github.com/settings/tokens
2. 点击 "Generate new token (classic)"
3. 填写备注（如：Blog Management）
4. 选择过期时间（建议 90 天）
5. **勾选 `repo` 权限**（必须！）
6. 点击生成，复制 Token（以 `ghp_` 开头）

### 2. 保存 Token
将 Token 告诉助手，例如：
```
我的 GitHub Token 是：ghp_xxxxxxxxxxxx
```

## ⚠️ 常见问题

### Q1: 构建失败怎么办？
**A:** 通常是 MDX 语法问题，助手会自动修复：
- `<` 符号 → 改为"小于"
- HTML 注释 `<!-- -->` → 改为 JSX 注释 `{/* */}`

### Q2: 图片不显示？
**A:** 确保：
1. 图片在 `public/` 目录
2. 文章中用 `/image.jpg` 引用（不是 `./image.jpg`）
3. 文件名大小写正确

### Q3: 文章没有立即显示？
**A:** Cloudflare Pages 需要 2-5 分钟部署：
1. 等待部署完成
2. 刷新页面（Ctrl+F5 强制刷新）
3. 检查 Cloudflare 仪表板的部署日志

### Q4: Token 过期了？
**A:** 重新生成 Token：
1. 访问 GitHub Token 设置页
2. 删除旧 Token
3. 生成新 Token（记得勾选 `repo` 权限）
4. 告诉助手新 Token

## 🔧 技术细节

### 仓库结构
```
astro-blog-starter-template/
├── src/content/blog/      # 文章目录
├── public/                # 静态资源（图片等）
├── src/components/        # 组件
├── src/layouts/           # 布局
├── src/styles/            # 样式
└── astro.config.mjs       # 配置文件
```

### 部署流程
1. 助手提交代码到 GitHub
2. GitHub 触发 Webhook
3. Cloudflare Pages 自动拉取代码
4. 执行 `npm run build`
5. 部署到全球 CDN
6. 更新生效（2-5 分钟）

### 监控部署
访问 Cloudflare Dashboard 查看：
- 构建日志
- 部署历史
- 错误信息
